# Branch Order Desk

Store-facing order visibility prototype, built for a Locus pre-sales demo.

A branch associate picks their store and can answer two questions: where is a
customer's order right now, and what is arriving at the branch today. Each sales
order expands to show its delivery and installation tasks as two linked rows,
flagged `SAME VISIT` where one last-mile crew does both.

**This is a demo prototype.** Customers, addresses and phone numbers are
synthetic. Task states, ETAs and crew names are illustrative.

Single static page, no build step, no dependencies beyond Google Fonts.
